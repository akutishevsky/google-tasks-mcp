# Due Time in Title Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `due` a timezone-safe calendar date and record the user's wall-clock due time as a structured title suffix, because Google's API discards times.

**Architecture:** A pure module `src/utils/due.ts` owns date normalisation, suffix formatting, suffix parsing and the response decoration. The three write tools in `src/tools/tasks.ts` call it before building the Google request; the read tools call it after `addReadableTimestamps()`. `addReadableTimestamps()` renders `due_readable` from the UTC date only.

**Tech Stack:** TypeScript, Zod (tool schemas), vitest + fast-check (tests), existing Google replay fake.

**Spec:** `docs/specs/2026-10-23-due-time-design.md`

## Global Constraints

- Suffix format exactly `(at 3:30 PM)`: qualifier, space, hour without leading zero, `:`, two-digit minutes, space, `AM`/`PM`. Midnight `12:00 AM`, noon `12:00 PM`.
- Suffix regex (read and replace): `/\s*\((at|before|by) (\d{1,2}):(\d{2}) (AM|PM)\)\s*$/i`.
- `due` sent to Google is always `YYYY-MM-DDT00:00:00.000Z`.
- Invalid `due` error text: `Invalid due date "<value>": expected YYYY-MM-DD`.
- No new dependencies. `.ts` import extensions. `import process from "node:process"` if used.
- Commits: Conventional Commits, on branch `feat/due-time` (master is protected).

## Review Focus

1. `due: "2025-01-15T22:00:00-08:00"` must store 15 January, not 16. Test in Task 1 (`keeps_date_part_verbatim`).
2. `due_readable` must not change when the server's `TZ` is west of UTC. Test in Task 2 (`due_readable_ignores_server_tz`).
3. A title that already has a suffix and receives a new `dueTime` must end with exactly one suffix. Test in Task 1 (`replaces_existing_suffix`).
4. `patch_task` with `dueTime` and no `title` must keep the user's existing title text. Test in Task 3 (`patch_task_due_time_keeps_title`).
5. A date like `2025-02-30` must be rejected before any Google call. Test in Task 1 (`rejects_impossible_dates`) and Task 3 (`insert_task_invalid_due_no_google_call`).

### Task 1: Pure due helpers

**Files:**
- Create: `src/utils/due.ts`
- Test: `test/unit/due.test.ts`

**Interfaces:**
- Produces:
  - `type DueTimeQualifier = "at" | "before" | "by"`
  - `const DUE_TIME_QUALIFIERS: readonly DueTimeQualifier[]`
  - `const DUE_TIME_PATTERN = /^([01]\d|2[0-3]):[0-5]\d$/` (24-hour `HH:MM`)
  - `normalizeDueDate(input: string): string` — `YYYY-MM-DD` or RFC 3339 in, `YYYY-MM-DDT00:00:00.000Z` out; throws `Error` with the Global Constraints message otherwise.
  - `formatDueTime(time: string, qualifier?: DueTimeQualifier): string` — `"15:30"` → `"(at 3:30 PM)"`.
  - `parseDueTime(title: string): { time: string; qualifier: DueTimeQualifier } | undefined` — inverse of `formatDueTime` on a title's suffix.
  - `withDueTime(title: string, time: string, qualifier?: DueTimeQualifier): string` — strips any existing suffix, then appends the new one unless `time === ""`.
  - `addDueTimeFields(data: unknown): unknown` — recursive over arrays/objects; for every object whose `title` parses, adds `due_time` and `due_time_qualifier`. Uses the same own-property `put` approach as `addReadableTimestamps`.

```ts
// test/unit/due.test.ts — Pure transforms. Oracle: examples + round-trip properties.
import { describe, expect, it } from "vitest";
import fc from "fast-check";
import { addDueTimeFields, formatDueTime, normalizeDueDate, parseDueTime, withDueTime } from "../../src/utils/due.ts";

describe("normalizeDueDate", () => {
  it("date_only_becomes_midnight_utc", () => {
    expect(normalizeDueDate("2026-10-20")).toBe("2026-10-20T00:00:00.000Z");
  });
  it("keeps_date_part_verbatim", () => {
    expect(normalizeDueDate("2025-01-15T22:00:00-08:00")).toBe("2025-01-15T00:00:00.000Z");
    expect(normalizeDueDate("2025-01-15T00:00:00.000Z")).toBe("2025-01-15T00:00:00.000Z");
  });
  it("rejects_impossible_dates", () => {
    for (const bad of ["2025-02-30", "2025-13-01", "tomorrow", "15/01/2025", ""]) {
      expect(() => normalizeDueDate(bad)).toThrow(`Invalid due date "${bad}": expected YYYY-MM-DD`);
    }
  });
  it("idempotent", () => {
    fc.assert(fc.property(
      fc.date({ min: new Date("2000-01-01T00:00:00Z"), max: new Date("2100-01-01T00:00:00Z"), noInvalidDate: true }),
      (d) => {
        const once = normalizeDueDate(d.toISOString().slice(0, 10));
        expect(normalizeDueDate(once)).toBe(once);
        expect(once.slice(0, 10)).toBe(d.toISOString().slice(0, 10));
      },
    ));
  });
});

describe("formatDueTime / parseDueTime", () => {
  it("examples", () => {
    expect(formatDueTime("15:30")).toBe("(at 3:30 PM)");
    expect(formatDueTime("03:30")).toBe("(at 3:30 AM)");
    expect(formatDueTime("16:30", "before")).toBe("(before 4:30 PM)");
    expect(formatDueTime("00:00")).toBe("(at 12:00 AM)");
    expect(formatDueTime("12:00", "by")).toBe("(by 12:00 PM)");
  });
  const hhmm = fc.tuple(fc.integer({ min: 0, max: 23 }), fc.integer({ min: 0, max: 59 }))
    .map(([h, m]) => `${String(h).padStart(2, "0")}:${String(m).padStart(2, "0")}`);
  const qualifier = fc.constantFrom("at", "before", "by" as const);
  it("round_trips", () => {
    fc.assert(fc.property(hhmm, qualifier, fc.string(), (time, q, title) => {
      expect(parseDueTime(`${title} ${formatDueTime(time, q)}`)).toEqual({ time, qualifier: q });
    }));
  });
  it("parse_is_case_insensitive_and_tolerates_trailing_space", () => {
    expect(parseDueTime("Dentist (AT 3:30 pm) ")).toEqual({ time: "15:30", qualifier: "at" });
  });
  it("parse_returns_undefined_without_suffix", () => {
    expect(parseDueTime("Dentist")).toBeUndefined();
    expect(parseDueTime("(at 3:30 PM) Dentist")).toBeUndefined();
  });
});

describe("withDueTime", () => {
  it("appends_with_one_space", () => {
    expect(withDueTime("Call the dentist", "15:30")).toBe("Call the dentist (at 3:30 PM)");
  });
  it("replaces_existing_suffix", () => {
    expect(withDueTime("Call the dentist (at 3:30 PM)", "16:30", "before")).toBe("Call the dentist (before 4:30 PM)");
  });
  it("empty_time_strips_suffix", () => {
    expect(withDueTime("Call the dentist (at 3:30 PM)", "")).toBe("Call the dentist");
    expect(withDueTime("Call the dentist", "")).toBe("Call the dentist");
  });
  it("never_stacks_suffixes", () => {
    const hhmm = fc.tuple(fc.integer({ min: 0, max: 23 }), fc.integer({ min: 0, max: 59 }))
      .map(([h, m]) => `${String(h).padStart(2, "0")}:${String(m).padStart(2, "0")}`);
    fc.assert(fc.property(fc.string(), fc.array(hhmm, { minLength: 1, maxLength: 5 }), (title, times) => {
      const out = times.reduce((t, time) => withDueTime(t, time), title);
      expect(out.match(/\((at|before|by) /g)?.length ?? 0).toBeLessThanOrEqual(
        (title.match(/\((at|before|by) /g)?.length ?? 0) + 1,
      );
      expect(parseDueTime(out)).toEqual({ time: times.at(-1), qualifier: "at" });
    }));
  });
});

describe("addDueTimeFields", () => {
  it("decorates_tasks_with_suffix_only", () => {
    const input = { items: [{ title: "A (at 3:30 PM)", due: "2026-10-20T00:00:00.000Z" }, { title: "B" }] };
    expect(addDueTimeFields(input)).toEqual({
      items: [
        { title: "A (at 3:30 PM)", due: "2026-10-20T00:00:00.000Z", due_time: "15:30", due_time_qualifier: "at" },
        { title: "B" },
      ],
    });
  });
  it("proto_key_copied_as_data", () => {
    const out = addDueTimeFields(JSON.parse('{"title":"t","__proto__":{"polluted":true}}')) as Record<string, unknown>;
    expect(Object.getPrototypeOf(out)).toBe(Object.prototype);
    expect(out.polluted).toBeUndefined();
  });
});
```

Update descriptions:

- `dueTimeQualifier`: `Word before the time in the title: "at" (default), "before" or "by". Only used with dueTime.`
- `dueMin`/`dueMax` on list_tasks: append ` Google compares against midnight UTC of the due date.`
